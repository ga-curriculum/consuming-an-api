## Third Party APIs

Third party APIs are APIs that are created by a company, orginaztion, or individual that is not you. They are a great way to add functionality to your application without having to build it yourself. There are APIs for almost anything you can think of, from weather to sports to movies to music. 

We can start expolering the options of third party APIs by looking in a couple of key places first:

- [Programmable Web](https://www.programmableweb.com/)
- [Rapid API](https://rapidapi.com/)
- [Awesome APIs](https://github.com/public-apis/public-apis)
- [Public APIs](https://publicapis.dev/)

However since third party APIs are created by someone else and these are currated lists it's always good to do a quick google search for the type of API you are looking for.

## API Documentation

We have found an API that we want to use, now what? The first thing we need to do is read the documentation. API documentation is a set of instructions that tell us how to use the API. It will tell us what endpoints are available, what data we can get from those endpoints, and how to make requests to those endpoints.

Documentation quality can vary from API to API. Some APIs have great documentation that is easy to read and understand, while others have documentation that is hard to read and understand. It's important to read the documentation carefully and make sure you understand it before you start to try to consume from it.

A couple of things to look for in the documentation:

- Does this API require an API key?
- Does this API have a rate limit? If so what is it?
- Are there any other restrictions on using this API?

API keys will require you to sign up for an account with the API provider before you can use the API. The rate limit is the number of requests you can make to the API in a given time period. If you exceed the rate limit you will get an error from the API. Other restrictions can include things like not being able to use the API for commercial purposes. All these are important things to know before you start using the API.
